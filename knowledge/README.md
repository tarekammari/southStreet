# قاعدة معرفة صخر AI — دليل الأعضاء

## 📋 نظرة عامة

هذا المجلد هو **قاعدة المعرفة الخاصة بصخر AI**. يمكن لأعضاء الوكالة إضافة وتحديث البيانات المتعلقة بالعروض والأسعار والرحلات والحج والعمرة.

صخر يقرأ هذه الملفات بشكل تلقائي ويستخدمها في إجاباته للعملاء.

---

## 🗂️ هيكل المجلدات

```
knowledge/
├── packages/       → باقات العمرة والحج (العروض والبرامج)
├── prices/         → الأسعار والتعريفات
├── flights/        → جداول الرحلات الجوية
├── offers/         → العروض الخاصة والتخفيضات
├── hajj/           → برامج الحج التفصيلية
├── umrah/          → دليل العمرة والمناسك
└── faq/            → الأسئلة الشائعة والإجابات
```

---

## ✏️ كيفية إضافة البيانات

### الطريقة 1: من لوحة الإدارة (Admin Panel)
1. اذهب إلى لوحة الإدارة → قسم **"قاعدة معرفة صخر"**
2. اختر التبويب المناسب (باقات / أسعار / رحلات / ...)
3. اكتب أو الصق النص مباشرة في المحرر
4. اضغط **"حفظ"**

### الطريقة 2: مباشرة في الملفات
- افتح الملف المناسب في المجلد (مثل `packages/packages_data.md`)
- أضف بياناتك باستخدام صيغة Markdown (عناوين وجداول)
- احفظ الملف

---

## 📝 قواعد كتابة البيانات

1. **استخدم العناوين** للتنظيم: `## اسم الباقة` أو `## الموضوع`
2. **استخدم الجداول** للأسعار والمقارنات
3. **استخدم النقاط** للقوائم والمزايا
4. **استخدم التظليل** للتأكيد: `**نص مهم**`
5. اكتب البيانات بالعربية أولاً، يمكن إضافة الفرنسية أو الإنجليزية
